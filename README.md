# 🧠 NutriPlan AI
NutriPlan AI – Hyper-Personalized AI-Powered Nutrition Assistant

NutriPlan AI is an intelligent, cross-platform nutrition assistant powered by Generative AI, Machine Learning, and real-time health integrations. Built using **Flutter** and **FastAPI**, it delivers **hyper-personalized meal plans**, tracks health metrics, supports **multilingual UI**, and provides **24/7 AI dietician support** — making it a true **virtual diet coach** for gym-goers, hostelers, elderly individuals, and anyone with dietary goals.

---

## 🚀 Key Features

- 🧬 AI-powered Meal Plan Generator (clinical + budget-based)
- 💪 Gymrat Mode: High-protein, muscle-gain optimized meals
- 🧓 Elderly & Accessibility Support (voice + simplified NLP)
- 🗣️ Multilingual UI: English, Tamil, Malayalam, Hindi, French
- 📡 Fitbit, Google Fit & Apple HealthKit integration
- 🤖 AI Dietician Chatbot (OpenAI / Rasa)
- 📶 Offline Mode (cached meal suggestions)
- ☁️ Firebase Authentication + Firestore DB
- 🧠 ML Recommender & Profile Classifier (Sklearn + Pandas)
- 🔒 Secure backend (FastAPI + JWT Auth)
